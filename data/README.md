# Required local data inputs

Copy these eight original files from the instructor-provided QSR Daily Demand dataset into this folder:

- `sales_R07.csv` — selected restaurant's item-day quantities and promotion flag
- `restaurants.csv` — identifies R07's city
- `menu_items.csv` — item names, menu categories, and listed prices
- `calendar.csv` — month, year, weekday, and holiday fields
- `weather.csv` — daily temperature and precipitation by city
- `events.csv` — event dates and event names by restaurant
- `menu_item_details.csv` — food costs, preparation times, and other item details
- `marketing_spend.csv` — monthly advertising spend and social posts

`restaurant_profile.csv` is part of the supplied bundle but is not used by the Stage 1 questions in this project version. It may stay in this folder; it is not required to render the pages.

Do not commit source CSVs to a public GitHub repository. The project's `.gitignore` excludes them. No sample or fabricated data is included in this project package.
