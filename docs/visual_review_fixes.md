# Revision 9 design choices

- Home page is short: one question, key facts, and links to the four reader-facing pages.
- Data page lists only the inputs used in the Stage 1 story and explains the joins in a small table.
- EDA now contains a guided exploratory sequence and four purposeful charts; the report retains the deeper business-story charts.
- The report follows one narrative: what sells → when demand changes → whether top products move together → promotion distributions → menu economics → weather/events → price/preparation/marketing checks → recommendations.
- Graph types are limited to the logic taught in Weeks 1–5. No machine learning, external charting framework, or unrelated dataset appears.
- Chart titles are section headings above the graph. Charts have no overlaid title that can collide with axes or toolbar controls.
- The report uses a wide responsive content grid and consistent palette, typography, and spacing.
- Weak price/preparation-time relationships are shown with scatterplots and a simple trend line; weak precipitation/social-post relationships are briefly noted rather than given extra headline charts.
- Conclusions are concise and observational; missing data is documented on the Exploration page without dominating the report story.
